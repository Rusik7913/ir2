КАК ПОЛУЧИТЬ ГОТОВЫЙ BIN БЕЗ УСТАНОВКИ БИБЛИОТЕК НА UBUNTU

1. Войдите на https://github.com/ и создайте новый репозиторий (New repository), например esp8266-ir-remote. Можно выбрать Public или Private.
2. Откройте репозиторий -> Add file -> Upload files.
3. Распакуйте этот архив на компьютере. Загрузите ВСЁ СОДЕРЖИМОЕ папки IR_Web_ESP8266_All_Protocols в корень репозитория, включая скрытую папку .github. Если скрытая папка не отображается в файловом менеджере, включите показ скрытых файлов (Ctrl+H).
4. Нажмите Commit changes.
5. Откройте вкладку Actions. Должен появиться запуск Build ESP8266 IR firmware. Откройте последний запуск.
6. Если сборка успешна (зелёная галочка), внизу страницы запуска в разделе Artifacts скачайте ESP8266-IR-firmware.zip.
7. Распакуйте его. Внутри будет .bin. Для стандартной прошивки приложения ESP8266 через веб-флэшер обычно используется адрес 0x00000 или 0x10000 в зависимости от типа бинарника и режима флэшера. Не прошивайте наугад: сначала пришлите скриншот страницы загрузки/поля адреса, чтобы проверить правильный режим.

Если сборка красная, откройте запуск Actions, скопируйте последние строки ошибки или пришлите скриншот.

ПРИМЕЧАНИЕ: сборка выполняется на GitHub Actions; архив содержит исходный проект и workflow, а не готовый .bin. Бинарник появится только после успешного запуска сборки.
