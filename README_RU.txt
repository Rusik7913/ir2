УНИВЕРСАЛЬНЫЙ ИК-ПУЛЬТ ESP8266

Функции:
- Две кнопки: принять и отправить.
- Сохраняет распознанное название протокола, код, число бит и raw-временные интервалы.
- Скачивание last_ir.txt через веб-страницу.
- Повторная передача raw-записи, что может работать для многих протоколов, даже если у библиотеки нет отдельной send-функции.

Важно:
- Нельзя гарантировать абсолютно все ИК-системы. Некоторые устройства используют нестандартную частоту несущей, длинные кадры, динамические коды, двунаправленную связь или нестандартную модуляцию.
- Начальная версия отправляет raw-запись с несущей 38 кГц. Для устройств с 36/40/56 кГц может понадобиться изменить значение в sendRaw.
- Для надёжного повтора нажми «Принять», направь пульт на приёмник и нажми кнопку несколько раз/удерживай её. Некоторые пульты передают отдельный повторный кадр при удержании, а эта простая версия сохраняет первый кадр.
- Приёмник: только после проверки распиновки, обычно OUT -> D5/GPIO14, GND -> GND, VCC -> 3V3 если поддерживает.
- ИК-светодиод передатчика/вход его драйвера -> D2/GPIO4. Для дальности используй транзисторный драйвер и резистор; не подключай голый мощный ИК-светодиод напрямую к GPIO.
- Wi-Fi не настроен в скетче по умолчанию: подключись к сети IR-ESP8266, пароль irremote8266, открой http://192.168.4.1.
- Требуется библиотека IRremoteESP8266 by crankyoldgit.
